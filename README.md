# FlareTV
A media server to rival plex, emby, jellyfin &amp; seanime!

# NOTICE! Documentation for plugin creation will be coming soon. 

This application is still a work in progress, but if you like what you see and everything that is built in, please do not hesitate to leave a star! Report all bugs & feature requests in the issues page please and thank you!

# Features
- Infinite Local Library Support
- Jellyfin server support
- Plugins
- Custom lists
- Quickshot metadata editing
- Seasonal Chips & Auto Sorting
- AniList NSFW Toggle (Default is off)
- Built-in Plugin Marketplace

# DMCA NOTICE!
FlareTV does not condone the use of Piracy, this app comes as is, without any loaded media on it aside from metadata. This is a BRING YOUR OWN MEDIA server, with Plugins to spice it up and make it more lively to use. All plugins run off of a custom Java sandbox engine to allow the use of extending the functionality of the program.
